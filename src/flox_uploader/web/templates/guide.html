Flox Uploader

Cet outil t'aide à uploader tes films et séries sur Gemini de la manière la plus propre possible. Mais il ne fait pas tout le boulot : tu dois rester vigilant, lire les règles Gemini, et vérifier chaque warning avant de cliquer Uploader.

{# ============================================================ PHILOSOPHIE — l'app comme assistant, pas comme bot ============================================================ #}

{{ icon('lightbulb', size='md') }} Philosophie : un assistant, pas un autopilote

L'app prend en charge le travail répétitif et fastidieux qui décourage de bien faire les uploads : génération du release_name compliant, parsing MediaInfo, calcul du .torrent, écriture du NFO, fiche BBCode formatée, vérification de doublon sur le tracker, calcul d'un score de confiance pour chaque package.

Ton rôle reste central : vérifier ce qui est généré, choisir quand override, et décider de cliquer Uploader. L'app fait des erreurs (variante FR mal détectée, TMDB ID ambigu, etc.) — c'est ton expertise qui ferme la boucle.

Si un cas particulier ne passe pas par l'app : copie les fichiers du dossier data/upload_packages/<nom>/ et finis l'upload manuellement sur Gemini. L'outil ne t'enferme pas.

{# Deux flows : 1 torrent vs batch #}
{# Flow A : 1 seul torrent #}

{{ icon('upload', size='sm', classes='text-primary-600 dark:text-primary-400') }} Flow simple — 1 torrent

Pour un seul upload, le plus rapide :

  1. Inbox → coche le fichier → "Ajouter à la queue"
  2. Attends que le score apparaisse (quelques secondes)
  3. Si score ≥ 90 et aucun warning : ouvre quand même le détail pour vérifier la variante FR et le TMDB
  4. Clique "Uploader vers le tracker" sur la page détail
{# Flow B : batch #}

{{ icon('list', size='sm', classes='text-primary-600 dark:text-primary-400') }} Flow batch — plusieurs torrents

Pour uploader 5–50 packages d'un coup, le pattern recommandé :

  1. Inbox → coche tous les fichiers → "Ajouter à la queue"
  2. Laisse les préparations finir (en background)
  3. Fais le tour de chaque package préparé : ouvre, vérifie, et clique Valider sans uploader pour le marquer comme "prêt à envoyer"
  4. Sur Queue, filtre par état "Validé"
  5. Coche tout (case "select all"), clique "Uploader la sélection"

L'état "Validé" sépare clairement "j'ai vérifié et c'est OK" du brouillon "préparé mais pas encore validé". Tu peux toujours cliquer à nouveau sur le bouton pour annuler la validation.

{# ============================================================ QUALITÉ DU FICHIER SOURCE — input = output ============================================================ #}

{{ icon('sparkles', size='md') }} Plus ton input est clean, plus ton score sera bon

L'app extrait l'information depuis le nom du fichier source et son MediaInfo. Si l'input est propre, le release_name généré sera direct et le score remontera tout seul. Si l'input est bricolé, l'app fera de son mieux mais tu devras override des champs à la main.

Ce qui aide :

  • Un nom de fichier qui suit le pattern scène (ex: Foo.2024.MULTi.VFF.1080p.BluRay.DDP5.1.x265-TEAM.mkv)
  • Pas de caractères spéciaux exotiques dans le titre (accent, &, etc.)
  • Variante FR explicite dans le nom (VFF/VFQ/VFB/VOF/VOQ) plutôt que juste "FRENCH"
  • Tracks audio bien tagguées dans MediaInfo (langue, titre type "VFF")
  • Sous-titres en SRT/UTF-8 plutôt que PGS uniquement (Gemini préfère le texte)

Note : pour un fichier mal nommé mais bon contenu, les overrides de la page détail permettent de tout corriger sans toucher au fichier source.

{# ============================================================ RESPONSABILITÉ UTILISATEUR — banner sérieux ============================================================ #}

{{ icon('alert-triangle', size='md') }} Ta responsabilité

Tu es responsable de tout ce que tu uploades sur le tracker. L'app fait des inférences ; elle se trompe parfois. Tu dois vérifier chaque upload :

  • Score < 90 : ouvre toujours le détail, lis chaque warning, vérifie le doublon, valide le naming.
  • Score 95–99 : un coup d'œil reste nécessaire — l'app peut s'être trompée sur la variante FR ou le TMDB.
  • Score 100 : statistiquement sûr, mais en cas de doute, ouvre le package avant l'upload.

En cas d'erreur d'upload, c'est sur le forum / wiki Gemini que tu dois te référer, pas sur cet outil.

{# ============================================================ PIÈGES COURANTS — variants, doublons, teams ============================================================ #}

Pièges récurrents

Les vrais cas où l'app demande ton attention.

{# 1. Variants FR #}

{{ icon('alert-triangle', size='sm', classes='text-warning-600 dark:text-warning-400') }} Variant VFF / VFQ / VFB mal indiqué

Les releases scène sont parfois étiquetées VFF alors que le doublage est en réalité VFQ (québécois) ou VFB (belge). L'app détecte ce qu'elle voit dans le nom ; elle ne devine pas ce qui ne s'y trouve pas.

À faire : si tu doutes, écoute 10 secondes du doublage, ou consulte un site spécialisé. Force la variante via l'override "Variante FR forcée" dans la page détail. L'icône drapeau dans la carte Technique t'indique la variante détectée par piste.

{# 2. Doublons #}

{{ icon('ban', size='sm', classes='text-danger-600 dark:text-danger-400') }} Doublons côté tracker

L'app contacte l'API Gemini avant l'upload pour vérifier qu'un torrent quasi-identique n'existe pas déjà. 3 niveaux de confiance :

  • Doublon certain : tailles identiques. L'upload est bloqué automatiquement.
  • Doublon probable : delta de taille faible. À toi de vérifier via le lien fourni.
  • Doublon ambigu : delta modéré. Possible re-encode du même fichier.

Sur la page détail, le bouton "Re-vérifier les doublons" rejoue le check (utile si tu as fait supprimer un doublon côté tracker entre-temps).

{# 3. Teams interdites + qualité source #}

{{ icon('shield', size='sm', classes='text-danger-600 dark:text-danger-400') }} Teams interdites + qualité du fichier

Gemini interdit certaines teams (qualité douteuse, re-encodes pourris). L'app détecte les teams blacklistées et bloque l'upload. La liste à jour est dans le wiki Gemini.

Tu peux ajouter tes propres teams interdites via la page Config (variable EXTRA_BANNED_TEAMS).

{# 4. Score stale après bug fix — rescore #}

{{ icon('refresh-cw', size='sm', classes='text-primary-600 dark:text-primary-400') }} Score périmé après mise à jour de l'app

Quand les règles de scoring évoluent (bug fixé, règle assouplie), les packages déjà préparés gardent leur ancien score. Pour rafraîchir sans regénérer le .torrent : bouton "Re-calculer le score" sur la page détail.

Sécurité : ne touche jamais à l'infohash du .torrent. Tu peux l'utiliser même sur un package déjà uploadé.

{# ============================================================ CONCEPTS — score ============================================================ #}

Comprendre le score

6 paliers, du parfait au bloqué.

  • {{ icon('sparkles', size='sm') }}100
    Parfait. Aucune approximation détectée. Coup d'œil de sécurité conseillé.
  • {{ icon('check', size='sm') }}95–99
    Quasi parfait. 1-2 fallbacks mineurs. Lecture rapide du détail.
  • {{ icon('arrow-up', size='sm') }}80–94
    Prêt / Bon. Quelques avertissements légers. Parcours-les avant l'upload.
  • {{ icon('alert-triangle', size='sm') }}60–79
    À vérifier. Plusieurs avertissements sérieux. Ouvre le détail, vérifie chaque ligne.
  • {{ icon('x', size='sm') }}< 60
    Bloqué. Au moins un problème dur (compliance, doublon certain). Override ou upload manuel.
